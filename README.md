# StudentSphere | Student Information Management Portal

A mobile-friendly student and admin management portal demo built with HTML, CSS, and Vanilla JavaScript.

## Features

- **Authentication Guard:** Secured admin portal requires authentic credentials to access.
- **Role Selection on Sign Up:** Option to register as either a Student or Admin.
- **Auto ID Generation:** Automatically assigns unique Student (`STU2026xxxx`) or Admin (`ADMINxxx`) IDs upon registration.
- **Student Dashboard:** View course details, grades, and percentage-based attendance.
- **Admin Tools:** Search, inspect, edit, or delete student profiles.
- **Local Storage Persistence:** All newly created student/admin profiles persist locally in your browser.
